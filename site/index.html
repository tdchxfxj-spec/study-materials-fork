HGhub 是一个基于 Tauri 构建的跨平台客户端项目。这里提供项目说明、源代码入口和各平台安装包下载。

下载最新版本 查看 GitHub 源码

关于这个项目

本项目主要以桌面和移动端应用的形式运行，需要 Tauri 提供系统能力。当前这个 GitHub Pages 页面是项目介绍与下载入口，并不是完整应用的网页版。

获取安装包

打开 GitHub Releases 页面，选择与你的设备对应的最新安装包。若暂时没有可用版本，请稍后查看项目发布记录。

Windows、macOS 与 Android 的构建产物以每次 Release 实际提供的文件为准。
